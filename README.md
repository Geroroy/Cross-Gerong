# 크로스 게롱 (Cross Gerong)

회색 고릴라 인형 **게롱이**가 주인공인 길 건너 친구들 스타일의 3D 복셀 게임입니다.
찻길, 강, 기찻길을 건너며 최대한 멀리 가고, 바나나를 모으세요.

## 실행

빌드 과정 없이 `index.html` 하나로 동작합니다 (three.js는 CDN에서 불러옵니다).

```bash
npx http-server .   # 또는 python3 -m http.server
```

브라우저에서 `index.html`을 바로 열어도 됩니다. GitHub Pages에 올리면 휴대폰에서도 플레이할 수 있어요.

## 조작

| 동작 | 키보드 | 터치 |
| --- | --- | --- |
| 앞으로 | ↑ / W / Space | 탭 또는 위로 스와이프 |
| 뒤로 | ↓ / S | 아래로 스와이프 |
| 왼쪽 / 오른쪽 | ← → / A D | 좌우 스와이프 |
| 시작 / 다시 하기 | Enter | 버튼 |

## 규칙

- **찻길**: 차와 트럭에 부딪히면 납작해져요.
- **강**: 통나무 위로만 건널 수 있어요. 통나무를 타고 화면 밖으로 떠내려가도 끝!
- **기찻길**: 신호등이 깜빡이면 기차가 옵니다.
- **꾸물거리기 금지**: 화면이 조금씩 앞으로 움직여서, 너무 오래 머물면 밀려나요.
- 최고 기록과 바나나 개수는 브라우저에 저장됩니다.

## 캐릭터

진회색 몸통, 연회색 얼굴과 큰 주둥이, 손발, 머리 위 털 한 줌, 위를 올려다보는 표정과
옆으로 살짝 내민 분홍 혀까지 실제 인형을 복셀로 옮겼습니다. 모델은 `index.html`의
`buildGorilla()` 함수에 있으니 색이나 비율을 바꿔 보세요.
