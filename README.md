# 크로스 게롱 (Cross Gerong)

경주 황리단길을 무대로 한 길 건너 친구들 스타일의 3D 복셀 게임입니다.
한옥 카페 골목, 찻길, 연못, 기찻길을 건너다 보면 대릉원, 천마총, 봉황대, 첨성대가 중간중간 나타나요.

## 실행

빌드 과정 없이 `index.html` 하나로 동작합니다 (three.js는 CDN에서 불러옵니다).

```bash
npx http-server .   # 또는 python3 -m http.server
```

브라우저에서 `index.html`을 바로 열어도 됩니다. GitHub Pages에 올리면 휴대폰에서도 플레이할 수 있어요.

## 모드

| 모드 | 목표 |
| --- | --- |
| 스토리 모드 | 황리단길에서 출발해 대릉원 → 천마총 → 첨성대 → 봉황대를 지나고, 형산강을 건너 **동국대학교 WISE캠퍼스 정문**(120칸)에 도착하면 완료. 걸린 시간과 최단 기록이 남아요. |
| 무한 모드 | 명소가 무작위 순서로 계속 나오는 끝없는 길. 최고 점수에 도전해요. |

스토리 모드에서는 화면 왼쪽 위에 남은 칸 수와 진행 막대, 걸린 시간이 보여요.
정문은 돌기둥 두 개와 주황 띠를 두른 들보, 양옆의 흰 코끼리상으로 만들었어요. 실제 정문 사진을 참고해 다듬을 예정이에요.

## 점수

- 앞으로 한 칸 갈 때마다 **+1점**
- 바나나 **+5점**, 가끔 나오는 황금 바나나 **+25점**
- 바나나는 골목, 고분 잔디밭, 연못 위 통나무에 놓여 있어요.
- 최고 기록은 브라우저에 저장됩니다.

## 맵

| 구간 | 내용 |
| --- | --- |
| 황리단길 골목 | 돌로 포장된 길 양옆에 카페, 찻집, 십원빵 가게 같은 한옥. 은행나무, 감나무, 석등, 화분, 빨간 우체통이 길을 막아요. |
| 찻길 | 승용차, 관광버스, 그리고 천천히 다니는 꽃마차 |
| 연못 | 연잎이 떠 있는 연못. 통나무를 타고 건너요. |
| 기찻길 | 기차는 아주 빨라요. 대신 오기 2.6초 전부터 길 양쪽 건널목 신호등이 번갈아 깜빡이고, 선로가 빨갛게 물들고, 땡땡 종이 울려요. |
| 명소 | 20~30칸마다 하나씩 무작위 순서로 나와요. 고분과 탑은 지나갈 수 없는 장애물이에요. |

명소 목록:

- **대릉원**: 크고 작은 고분이 모인 잔디밭과 소나무
- **천마총**: 고분과 돌로 된 입구
- **봉황대**: 꼭대기에 느티나무가 자라는 큰 고분
- **첨성대**: 돌을 쌓아 올린 천문대와 가을 꽃밭(핑크뮬리, 노란 꽃)

## 스킬

화면 오른쪽 아래 동그란 버튼을 누르거나 **Q**(또는 Shift) 키로 써요. 쓰고 나면 버튼에 남은 대기 시간이 보여요.

| 캐릭터 | 스킬 | 효과 | 대기 |
| --- | --- | --- | --- |
| 게롱 | 게롱펀치 | 앞으로 7칸 일직선에 있는 장애물·관광객·차를 날려버려요 | 15초 |
| 꽃순이 (엎드린 자세) | 꽃치기 | 2초 동안 닌자고의 스핀짓주처럼 회오리를 일으키며 돌아요. 주변 반경 2.3칸, 360도 안의 장애물·관광객·차를 계속 날려버리고, 도는 동안은 기차에도 끄떡없어요. 범위는 꽃순킥보다 작아요 | 20초 |
| 꽃순이 (선 자세) | 꽃순킥 | 앞으로 5칸, 멀어질수록 넓어지는 부채꼴 범위를 날려버려요. 선 자세에서는 무릎을 당겼다가 다리를 쭉 뻗어 부채꼴로 휘두르고, 바닥에 분홍 부채꼴과 꽃잎이 퍼져요 | 18초 |
| 숭돌이 | 바나나 주세요 | 20초 동안 바나나를 두 배로 얻어요 (개수와 점수 모두) | 35초 |
| 포롱이 | 포차드 | 자동 발동. 게임 오버 순간 한 번 다시 일어나요. 물에 빠지면 가까운 땅으로 돌아가고, 2.5초 동안 차와 기차에 부딪혀도 괜찮아요 | 한 판에 1회 |

고분이나 첨성대 같은 명소는 날아가지 않아요. 스킬마다 캐릭터가 움직이는 동작 애니메이션이 있어요. 천마와 십원빵은 아직 스킬이 없어요.

## 기록 · 순위

시작 화면의 **기록 · 순위**에서 볼 수 있어요.

- **무한 순위 / 스토리 순위**: claude.ai에 올린 페이지에서는 같은 링크로 들어온 사람들의 최고 기록이 함께 모여요(무한은 점수, 스토리는 완주 시간). 사람마다 가장 좋은 기록 하나가 남아요.
- 저장소의 `index.html`을 직접 열면 함께 보는 순위가 없으니, 그 기기에 저장된 기록끼리 순위를 보여줘요.
- **내 기록**: 이 기기에서 한 최근 30판(모드, 캐릭터, 점수, 거리, 바나나, 시간)

## 게임 오버와 도착

- 물에 빠지면 허우적거리다 가라앉고, 결과 카드는 화면 아래에 작게 떠요.
- 게임 오버 화면에서 **다른 캐릭터로 이어하기**를 고르면 가까운 안전한 칸에서 그 캐릭터로 계속해요(2초 무적).
- 스토리 모드에서 정문에 도착하면 진흥관 영어영문학과 수업 컷씬이 나오고, 끝나거나 건너뛰면 결과 화면이 떠요.

## 꾸미기

시작 화면의 **갤러리 · 꾸미기**를 누르면 돌 받침대 위에 캐릭터가 크게 서 있는 갤러리가 열려요.

- 화면을 드래그하면 360° 돌려 볼 수 있고, 위아래로 끌면 내려다보는 각도가 바뀌어요. 마우스 휠로 확대·축소, 방향키로도 돌릴 수 있어요.
- **앞 / 옆 / 뒤** 버튼으로 바로 그 방향을 보고, **자동 회전**으로 천천히 돌게 할 수 있어요.
- ‹ › 로 캐릭터를 바꾸고, 아래 옷·머리 장식을 눌러 바로 입혀 봐요. 닫으면 고른 캐릭터와 옷 그대로 출발해요.

갤러리에서 캐릭터에게 옷과 머리 장식을 입힐 수 있어요. 게임에서 모은 바나나가 지갑에 쌓이고, 그 바나나로 장식을 열어요.
한 번 연 장식은 모든 캐릭터가 쓸 수 있고, 캐릭터마다 입은 옷을 따로 기억해요. 잠긴 장식도 입어 볼 수는 있어요.

| 종류 | 이름 | 값 |
| --- | --- | --- |
| 옷 | 색동저고리 (빨간 치마, 무지개 소매 줄무늬, 옷고름) | 무료 |
| 옷 | 도령 한복 (흰 저고리, 남색 조끼, 하늘색 바지) | 바나나 15 |
| 옷 | 곤룡포 (붉은 임금 옷, 금빛 흉배, 옥대) | 바나나 30 |
| 머리 | 갓 | 무료 |
| 머리 | 화관 | 바나나 15 |
| 머리 | 신라 금관 (나뭇가지 모양 장식과 곡옥) | 바나나 40 |

한복을 입고 다니면 관광객이 "한복 잘 어울려요!"라고 말해 주기도 해요. 옷은 캐릭터마다 몸통 크기(`fit`)에 맞춰 만들어져서,
`OUTFITS`나 `HATS` 배열에 항목을 추가하면 모든 캐릭터에 바로 입힐 수 있어요.

## 지나가는 사람들

골목과 명소 잔디밭에는 관광객이 돌아다녀요.

- **한복 입은 외국인 관광객**: 치마저고리에 댕기, 갓을 쓴 사람도 있어요.
- **관광객**: 모자, 백팩, 카메라를 든 사람들. 가끔 멈춰서 사진을 찍어요(찰칵!).
- 사람은 장애물이라 부딪히면 "앗!" 하고 길을 막아요. 차처럼 다치지는 않아요.
- 옆을 지나가면 "Wow, so cute!", "한복 예쁘죠?", "게롱이다!"처럼 말을 걸어요. 명소 근처에서는 그 명소 이야기를 해요.

## 캐릭터

| 이름 | 설명 |
| --- | --- |
| 게롱 | 회색 고릴라 인형. 진회색 몸에 연회색 얼굴, 위를 올려다보며 분홍 혀를 살짝 내밀어요. |
| 꽃순이 | 주황 원숭이 인형. 넓은 크림색 얼굴과 반짝이는 눈, 큰 주둥이, 입꼬리가 올라간 웃는 입과 오른쪽으로 내민 분홍 혀. **엎드린 자세**(기본, 팔을 양옆으로 쭉 뻗음)와 게롱처럼 두 발로 **선 자세** 중에서 시작 화면이나 갤러리에서 고를 수 있어요. |
| 숭돌이 | 갈색 원숭이 인형. 하트 모양 얼굴, 끝이 말려 올라간 웃는 입, 초록 뼈다귀 무늬 잠옷. |
| 포롱이 | 동그란 하얀 인형. 하얀 반짝임이 있는 까만 눈, 끝이 살짝 올라간 가는 웃는 입, 시바견 얼굴이 그려진 겨자색 수면잠옷. |
| 천마 | 천마총에서 나온 말다래 그림 속 하얀 말 |
| 십원빵 | 등에 다보탑이 새겨진 경주 간식, 옆으로 치즈가 흘러나와요. |

캐릭터 모델은 `index.html`의 `buildGerong()`, `buildKkotsuni()`, `buildSungdol()`, `buildPorong()`,
`buildCheonma()`, `buildSipwon()`에 있고, `CHARACTERS` 배열에 하나 더 추가하면 선택 화면에 바로 나타나요.
