# 크로스 게롱 (Cross Gerong)

경주 황리단길을 무대로 한 길 건너 친구들 스타일의 3D 복셀 게임입니다.
한옥 카페 골목, 찻길, 연못, 기찻길을 건너다 보면 대릉원, 천마총, 봉황대, 첨성대가 중간중간 나타나요.

## 실행

빌드 과정 없이 `index.html` 하나로 동작합니다 (three.js는 CDN에서 불러옵니다).

```bash
npx http-server .   # 또는 python3 -m http.server
```

브라우저에서 `index.html`을 바로 열어도 됩니다. GitHub Pages에 올리면 휴대폰에서도 플레이할 수 있어요.

## 점수

- 앞으로 한 칸 갈 때마다 **+1점**
- 바나나 **+5점**, 가끔 나오는 황금 바나나 **+25점**
- 바나나는 골목, 고분 잔디밭, 연못 위 통나무에 놓여 있어요.
- 최고 기록은 브라우저에 저장됩니다.

## 맵

| 구간 | 내용 |
| --- | --- |
| 황리단길 골목 | 돌로 포장된 길 양옆에 카페, 찻집, 십원빵 가게 같은 한옥. 은행나무, 감나무, 석등, 화분, 빨간 우체통이 길을 막아요. |
| 찻길 | 승용차, 관광버스, 그리고 천천히 다니는 꽃마차 |
| 연못 | 연잎이 떠 있는 연못. 통나무를 타고 건너요. |
| 기찻길 | 신호등이 깜빡이면 기차가 옵니다. |
| 명소 | 20~30칸마다 하나씩 무작위 순서로 나와요. 고분과 탑은 지나갈 수 없는 장애물이에요. |

명소 목록:

- **대릉원**: 크고 작은 고분이 모인 잔디밭과 소나무
- **천마총**: 고분과 돌로 된 입구
- **봉황대**: 꼭대기에 느티나무가 자라는 큰 고분
- **첨성대**: 돌을 쌓아 올린 천문대와 가을 꽃밭(핑크뮬리, 노란 꽃)

## 꾸미기

시작 화면의 **꾸미기**에서 캐릭터에게 옷과 머리 장식을 입힐 수 있어요. 게임에서 모은 바나나가 지갑에 쌓이고, 그 바나나로 장식을 열어요.
한 번 연 장식은 모든 캐릭터가 쓸 수 있고, 캐릭터마다 입은 옷을 따로 기억해요. 잠긴 장식도 입어 볼 수는 있어요.

| 종류 | 이름 | 값 |
| --- | --- | --- |
| 옷 | 색동저고리 (빨간 치마, 무지개 소매 줄무늬, 옷고름) | 무료 |
| 옷 | 도령 한복 (흰 저고리, 남색 조끼, 하늘색 바지) | 바나나 15 |
| 옷 | 곤룡포 (붉은 임금 옷, 금빛 흉배, 옥대) | 바나나 30 |
| 머리 | 갓 | 무료 |
| 머리 | 화관 | 바나나 15 |
| 머리 | 신라 금관 (나뭇가지 모양 장식과 곡옥) | 바나나 40 |

한복을 입고 다니면 관광객이 "한복 잘 어울려요!"라고 말해 주기도 해요. 옷은 캐릭터마다 몸통 크기(`fit`)에 맞춰 만들어져서,
`OUTFITS`나 `HATS` 배열에 항목을 추가하면 모든 캐릭터에 바로 입힐 수 있어요.

## 지나가는 사람들

골목과 명소 잔디밭에는 관광객이 돌아다녀요.

- **한복 입은 외국인 관광객**: 치마저고리에 댕기, 갓을 쓴 사람도 있어요.
- **관광객**: 모자, 백팩, 카메라를 든 사람들. 가끔 멈춰서 사진을 찍어요(찰칵!).
- 사람은 장애물이라 부딪히면 "앗!" 하고 길을 막아요. 차처럼 다치지는 않아요.
- 옆을 지나가면 "Wow, so cute!", "한복 예쁘죠?", "게롱이다!"처럼 말을 걸어요. 명소 근처에서는 그 명소 이야기를 해요.

## 캐릭터

| 이름 | 설명 |
| --- | --- |
| 게롱 | 회색 고릴라 인형. 진회색 몸에 연회색 얼굴, 위를 올려다보며 분홍 혀를 살짝 내밀어요. |
| 꽃순이 | 주황 원숭이 인형. 팔을 양옆으로 쭉 뻗고 엎드린 자세, 넓은 크림색 얼굴과 반짝이는 눈, 큰 주둥이, 말린 분홍 콧구멍. |
| 숭돌이 | 갈색 원숭이 인형. 하트 모양 얼굴, 끝이 말려 올라간 웃는 입, 초록 뼈다귀 무늬 잠옷. |
| 포롱이 | 동그란 하얀 인형. 하얀 반짝임이 있는 까만 눈, 끝이 살짝 올라간 가는 웃는 입, 시바견 얼굴이 그려진 겨자색 수면잠옷. |
| 천마 | 천마총에서 나온 말다래 그림 속 하얀 말 |
| 십원빵 | 등에 다보탑이 새겨진 경주 간식, 옆으로 치즈가 흘러나와요. |

캐릭터 모델은 `index.html`의 `buildGerong()`, `buildKkotsuni()`, `buildSungdol()`, `buildPorong()`,
`buildCheonma()`, `buildSipwon()`에 있고, `CHARACTERS` 배열에 하나 더 추가하면 선택 화면에 바로 나타나요.
