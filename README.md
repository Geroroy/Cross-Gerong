# 크로스 게롱 (Cross Gerong)

경주 황리단길을 무대로 한 길 건너 친구들 스타일의 3D 복셀 게임입니다.
한옥 카페 골목, 찻길, 연못, 기찻길을 건너다 보면 대릉원, 천마총, 봉황대, 첨성대가 중간중간 나타나요.

## 실행

빌드 과정 없이 `index.html` 하나로 동작합니다 (three.js는 CDN에서 불러옵니다).

```bash
npx http-server .   # 또는 python3 -m http.server
```

브라우저에서 `index.html`을 바로 열어도 됩니다. GitHub Pages에 올리면 휴대폰에서도 플레이할 수 있어요.

## 조작

| 동작 | 키보드 | 터치 |
| --- | --- | --- |
| 앞으로 | ↑ / W / Space | 탭 또는 위로 스와이프 |
| 뒤로 | ↓ / S | 아래로 스와이프 |
| 왼쪽 / 오른쪽 | ← → / A D | 좌우 스와이프 |
| 캐릭터 고르기 (시작 화면) | ← → | ‹ › 버튼 |
| 시작 / 다시 하기 | Enter | 버튼 |

## 점수

- 앞으로 한 칸 갈 때마다 **+1점**
- 바나나 **+5점**, 가끔 나오는 황금 바나나 **+25점**
- 바나나는 골목, 고분 잔디밭, 연못 위 통나무에 놓여 있어요.
- 최고 기록은 브라우저에 저장됩니다.

## 맵

| 구간 | 내용 |
| --- | --- |
| 황리단길 골목 | 돌로 포장된 길 양옆에 카페, 찻집, 십원빵 가게 같은 한옥. 은행나무, 감나무, 석등, 화분, 빨간 우체통이 길을 막아요. |
| 찻길 | 승용차, 관광버스, 그리고 천천히 다니는 꽃마차 |
| 연못 | 연잎이 떠 있는 연못. 통나무를 타고 건너요. |
| 기찻길 | 신호등이 깜빡이면 기차가 옵니다. |
| 명소 | 20~30칸마다 하나씩 무작위 순서로 나와요. 고분과 탑은 지나갈 수 없는 장애물이에요. |

명소 목록:

- **대릉원**: 크고 작은 고분이 모인 잔디밭과 소나무
- **천마총**: 고분과 돌로 된 입구
- **봉황대**: 꼭대기에 느티나무가 자라는 큰 고분
- **첨성대**: 돌을 쌓아 올린 천문대와 가을 꽃밭(핑크뮬리, 노란 꽃)

## 캐릭터

| 이름 | 설명 |
| --- | --- |
| 게롱 | 회색 고릴라 인형. 진회색 몸에 연회색 얼굴, 위를 올려다보며 분홍 혀를 살짝 내밀어요. |
| 오롱 | 주황 원숭이 인형. 엎드린 자세에 크림색 하트 모양 눈가와 큰 손발, 분홍 콧구멍. |
| 천마 | 천마총에서 나온 말다래 그림 속 하얀 말 |
| 십원빵 | 등에 다보탑이 새겨진 경주 간식, 옆으로 치즈가 흘러나와요. |

캐릭터 모델은 `index.html`의 `buildGerong()`, `buildOrong()`, `buildCheonma()`, `buildSipwon()`에 있고,
`CHARACTERS` 배열에 하나 더 추가하면 선택 화면에 바로 나타나요.
